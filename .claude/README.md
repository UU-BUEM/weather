# .issues/ — known issues & decisions log

Git-tracked log so recurring items don't need re-explaining each session.

## For Claude Code
- **Check `open.md` before starting** work on a provider; respect
  RESOLVED/BY-DESIGN in `resolved.md` so you don't re-raise settled points.
- When you hit or fix something, UPDATE these files in the same change.
- One-liners; newest at top. Keep markdownlint-clean.

## Files
- `open.md` — active TODOs by provider (incl. the 2 next major tasks).
- `resolved.md` — fixed bugs + settled/BY-DESIGN decisions.
